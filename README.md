# What is this?
This is the best clicker game that you'll ever see! It's basicilly clicker game in which you earn bytes and RAM



# How to play:
 - Click to collect bytes!
 - Upgrade your ram to get even MORE bytes!
 - Try to get as more as you can!


# What did we use?
 - Godot Engine 4
 - GD Script
